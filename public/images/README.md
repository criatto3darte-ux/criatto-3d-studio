# Imagens da loja
- `banner/` — foto do banner principal (configure `heroImage` em `src/shared/config/store.config.ts`, ex.: `/images/banner/hero.jpg`).
- `categorias/` — uma imagem por categoria (campo `image` em `src/features/catalog/categories.ts`).
- `produtos/` — fotos dos produtos (campo `images` de cada produto).
Sem arquivo, os componentes exibem um espaço reservado ilustrativo. Recomenda-se JPG/WebP, proporção 1:1 para produtos e categorias, 16:11 para o banner.
